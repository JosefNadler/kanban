# Scripts guide

This folder contains start and stop helpers for local Docker-based runs.

## Linux

- [start-linux.sh](./start-linux.sh): builds and starts the app container in detached mode.
- [stop-linux.sh](./stop-linux.sh): stops and removes app container resources.

## macOS

- [start-mac.sh](./start-mac.sh): builds and starts the app container in detached mode.
- [stop-mac.sh](./stop-mac.sh): stops and removes app container resources.

## Windows (PowerShell)

- [start-windows.ps1](./start-windows.ps1): builds and starts the app container in detached mode.
- [stop-windows.ps1](./stop-windows.ps1): stops and removes app container resources.
